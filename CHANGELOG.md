# Changelog

## 1.0.0

First release: 50 tools to create, install and operate VirtualBox VMs.

- VM lifecycle, snapshots, clones, import/export, disk resize and unattended OS installs.
- Vision loop for any installer: screenshots, keyboard, mouse and clipboard paste.
- Text control once the OS is up: Guest Additions, SSH (with host key checking), WinRM and serial console.
- Networking: NIC modes, NAT networks, port forwards, cable plug/unplug, guest IP discovery without Guest Additions.
- Safety: read-only mode, clean ACPI shutdown by default, passwords kept off the command line.
